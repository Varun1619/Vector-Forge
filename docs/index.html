How this page works

No API, no server, no database — just a static page and a browser doing real ML inference.

  1. 1

    Fetch & embed

    A scheduled GitHub Action pulls the newest cs.AI papers from the arXiv API and embeds each abstract with sentence-transformers/all-MiniLM-L6-v2.

  2. 2

    Commit & publish

    The Action commits the refreshed vectors as a static JSON file. GitHub Pages republishes it automatically — no deploy step, no server to run.

  3. 3

    Embed in-browser

    When you search, transformers.js loads the same model (as ONNX) and embeds your query locally — your text never leaves the device.

  4. 4

    Rank & render

    Cosine similarity between your query vector and every paper vector runs client-side in plain JavaScript, and the closest matches render instantly.
